# JPA Authentication & JWT Token

A mini Spring Boot project demonstrating user authentication using Spring Data JPA and JSON Web Token (JWT).

## Features

* User entity and Role entity
* User persistence with Spring Data JPA
* User registration and login
* Password hashing with BCrypt
* JWT token generation and validation
* API testing with Postman
* Basic authentication without role-based authorization

## Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* JWT
* MySQL
* Maven
* Postman

## Testing

Use Postman to test user registration, login, JWT generation, and access to protected endpoints.

## Project Status

This project is for learning and practicing authentication with Spring Boot and JWT. Role-based authorization is not implemented yet.

## Future Improvements

* Role-based authorization
* Refresh tokens
* Improved exception handling
* Input validation
